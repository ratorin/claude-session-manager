## 🔴 設計判断要 (要ユーザー確認、各 1〜2 セッション)

### TASK-5: `claude agents` コマンドとの棲み分け or 統合 🔥🔥🔥

- **背景**: Claude Code 2.1.139 で `claude agents` コマンド (Agent View) が登場
  - 全 Claude Code セッション (running / blocked / done) を単一リスト表示
  - CSM の中核機能と直接重複
- **オプション**:
  - **A: 完全棲み分け** — CSM は「セッション履歴 + メモリ + プロジェクト + 組織図」専門、`claude agents` は「ライブ稼働状態」専門。重複機能を CSM から削除
  - **B: 統合表示** — CSM Sidebar 内に `claude agents` の情報を埋め込み (child_process で `claude agents --cwd <ws>` 実行 → JSON パース)
  - **C: 並行運用** — 何もしない (重複表示のまま)
- **推奨**: B (CSM の "ライブ状態" タブとして `claude agents` を埋め込み)
- **規模**: 大 (設計 + 実装で 2〜3 cycle)
- **担当**: csm-planner で設計 → csm-impl + csm-ui で実装
