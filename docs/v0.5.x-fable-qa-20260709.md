## 1. CRITICAL（Fable関連の実バグ）

### C-1: `claude-fable-5[1m]` が **sonnet-1m に誤変換**される
- `agentUtils.ts:66` の `[1m]` 判定が fable 判定（68行）より**先に評価**されるため、`fable[1m]` / `claude-fable-5[1m]` は「opusを含まない」→ `sonnet-1m` に化ける。
- 実害: frontmatter に `model: claude-fable-5[1m]` を持つエージェントは一覧で「Sonnet 1M」と誤表示。**フォームで別項目を1つ編集して保存、またはセッション紐づけ操作（dataStore.addAgent は常に書き戻す）だけで frontmatter が `sonnet[1m]` に恒久書き換え**。agentCommands.ts:490 のクイックフィックスでも同じ。
- resolveModelName（agentFormPanel.ts:83）は同じ入力を `opus-1m` に解決しており、normalizeModel と不整合＝意図しない挙動の証左。

### C-2: fable → opus のサイレント書き換え
- normalizeModel が fable を opus に丸め、保存時に frontmatter 自体が `opus` に書き換わる（fable情報の破壊）。
- 過去にCSM経由で保存済みのファイルは**既に opus に書き換わっていて復元不能** → リリースノートに「Fable利用エージェントはモデルを再選択」と明記が必要。
