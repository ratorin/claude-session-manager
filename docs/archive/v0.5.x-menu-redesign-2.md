# CSM v0.5.x — 右クリックメニュー再設計 v2（重複排除版）

> **版数**: v2.0
> **作成日**: 2026-05-28
> **作成者**: csm-planner
> **対象**: v0.5.x の現行 contextMenu（claudeAgents / claudeAgentsFavorites 二重登録問題の解消含む）
> **前回**: [`v050-menu-redesign.md`](./v050-menu-redesign.md) — 31項目→13ユニークの初版整理

---

## 0. 背景

v0.5.0 で **お気に入りツリー** (`claudeAgentsFavorites`) が新規追加された結果、`agentTreeProvider` の context menu が **claudeAgents / claudeAgentsFavorites の両ビューに二重登録される**事態が発生。実機 `package.json` を確認したところ：

- `previewAgent` / `openAgentInClaude` / `openAgentSession` がそれぞれ2回登録
- `addAgentFavorite` / `removeAgentFavorite` は inline と `2_favorite` の2グループで重複登録
- group 順序が `0_open` / `0_link` / `1_edit` / `2_copy` / `2_favorite` / `3_danger` と **2_系で衝突**

この v2 設計書は **claudeAgentsFavorites 追加後の構造に即した再整理**を行う。

## 2. 再設計指針（v2）

### 2.1 設計原則（v1 を踏襲・拡張）

1. **inline は最大1個** — 1行に出るアイコンは1機能（state でアイコン差し替え）
2. **view 共通の context menu は when 条件を OR 結合して1ヶ所に書く** — claudeAgents と claudeAgentsFavorites の重複を when 句で吸収
3. **group 順序を固定**：`0_open` → `1_edit` → `2_link` → `3_danger`（v1 と同じ）+ **inline は star toggle のみ**
4. **`@`順序指定を必須化** — 同 group 内のすべてのコマンドに `@N` を付与（順序保証）
5. **action verb で命名統一** — `openAgentInClaude` → `runAgentInIDE` 等（v050 v1 案を再採用）

### 2.2 when 句の OR 統合パターン

**旧**（重複登録）:
```json
{ "command": "claudeManager.previewAgent",
  "when": "view == claudeAgents && viewItem =~ /agentItemLinked/" },
{ "command": "claudeManager.previewAgent",
  "when": "view == claudeAgentsFavorites && viewItem =~ /favoriteAgentLinked/" }
```

**新**（1行）:
```json
{ "command": "claudeManager.previewAgent",
  "when": "(view == claudeAgents || view == claudeAgentsFavorites) && viewItem =~ /(agentItemLinked|favoriteAgentLinked)/",
  "group": "0_open@1" }
```

→ **登録数 半減**。viewItem 命名規約 (`agentItemLinked` / `favoriteAgentLinked`) を維持しつつ、メニュー定義は単一化。

### 2.3 inline と group 2_favorite の整理

inline と group 2_favorite の **同時登録は禁止**。inline トグル（★/unstar）を **単一の context-specific アイコン**として残し、コンテキストメニュー本体からは外す。

理由：右クリックメニューで「★お気に入りに追加」と inline ★ が両方クリック可能だと **同じ操作の2導線**になり、ユーザーが混乱する。

## 3. 整理後のメニュー構成（v2）

### 3.1 セッション系

```
[行] セッション名                              [⭐]  ← inline (bookmark toggle)

右クリック:
─────────────── 0_open
🔵 Claude で開く                @1
🔵 プレビュー                   @2
📋 コピー... ▶                  @3  (サブ: ID / パス)
─────────────── 1_edit
✏️ リネーム                     @1
🏷  タグを編集 ▶                @2  (サブ: 追加 / 削除)
─────────────── 2_link
🔗 エージェントとして登録      @1  (未登録のみ)
🔗 紐づくエージェントを開く    @2  (登録済のみ)
─────────────── 3_danger
🗑 セッションを削除             @1
```

→ **9項目**（うち2はサブメニュー）

### 3.2 エージェント系（claudeAgents + claudeAgentsFavorites 共通）

```
[行] エージェント名 [モデル] [🌐] [🟢]            [⭐]  ← inline (favorite toggle)

右クリック:
─────────────── 0_open
🔵 起動 ▶                       @1  (サブ: IDE / ターミナル(ルール適用))
🔵 プレビュー                   @2
🔄 セッションを新しくする       @3
📋 コピー... ▶                  @4  (サブ: セッションID / セッションパス)
─────────────── 1_edit
✏️ エージェント設定を編集       @1
✏️ 役割ファイルを編集           @2  (役割ファイル存在時のみ)
+ 機能追加（スニペット挿入）    @3
─────────────── 2_link
🔗 セッションを紐づけ           @1  (未紐づけ時のみ)
🔗 親エージェントを開く         @2  (親がいる時)
🔗 配下を組織図で見る           @3  (子がいる時)
─────────────── 3_danger
🗑 エージェントを削除           @1  (guarded=true は無効)
```

→ **11項目**（うち2はサブメニュー）
**inline からはお気に入りトグルのみ。コンテキストメニュー本体から `addAgentFavorite/removeAgentFavorite` は除外**。

### 3.4 ワークフローセクション（将来 — v0.5.x Phase A 以降）

─────────────── 3_danger（将来）

→ **3〜5項目**
