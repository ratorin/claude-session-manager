# ⑤ 組織図を開いて確認

Cytoscape ベースの組織図で、エージェントの親子関係と稼働状態を俯瞰できます。

## 使えるビュー

- **ツリー / 関係 / グループ** の 3 レイアウト切替
- **モデル別 / 親エージェント別** フィルタ
- **検索ボックス**（v0.5.18 §4-11）で名前・役割の高速あいまい検索 → 一致ノードにズーム
- **凡例チップクリック**で該当色モデル or 稼働中のみハイライト

## エクスポート

右上の PNG / SVG ボタンで組織図を保存できます。ドキュメント貼り付けに便利です。

## 完了

これで CSM の基本セットアップは終了です。困ったときは「使い方ガイドを開く」（ステータスバー右）を参照してください。
