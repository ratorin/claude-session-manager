# ⑤ 組織図を開いて確認

v0.5.23 で全面リデザイン。Obsidian 風の力学グラフを中心に、エージェントの親子関係・稼働状態・連携履歴を俯瞰できます。

## 3 つのサブモード（ツールバーのセグメント）

- **グラフ**（既定） — 自前 Canvas による力学グラフ。ダーク固定。ノードをドラッグで自由に配置、ホバーで隣接ハイライト、クリックで既存動作（履歴プレビュー等）。
- **階層** — カードツリー。VS Code テーマ追従。カードに `displayName / モデルバッジ / 稼働ドット / 部下数` を表示。
- **グループ** — 部署別 / モデル別 / 稼働状態別（稼働中 / 待機 / 未紐づけ）のチップ切替でクラスタリング。VS Code テーマ追従。

既定モードは設定 `claudeManager.orgChart.defaultMode`（`graph` / `tree` / `group`）で変更可能。ツールバーでの切替もその設定に永続化されます。

## 検索・凡例フィルタ

- **検索ボックス**（名前・役割）で一致ノードを絞り込み。グラフモードではマッチ最初の 1 件をセンタリング。
- **凡例チップ**（Fable / Opus / Sonnet / Haiku / 稼働中）で該当のみハイライト。もう一度クリックで解除。

## 連携レイヤー

ツールバー右上の **連携** ボタンで、`/csm-ask-agent` の直近 7 日の送信履歴（`~/.claude/csm-collab-log.jsonl`）を金色点線でグラフに重ね描き。線の太さは送信回数を反映。

## 他プロジェクトを隠す

**他プロジェクトを隠す** トグルで、現ワークスペース外のエージェントを非表示化。`agent.workDir` を現ワークスペース群と照合。`workDir` 未設定は全プロジェクト共通扱いで常に表示。トグル状態は設定 `claudeManager.orgChart.hideOtherProjects` に永続化されます。

## 完了

これで CSM の基本セットアップは終了です。困ったときは「使い方ガイドを開く」（ステータスバー右）を参照してください。
