# ① Claude Code の確認

Claude Session Manager は Claude Code (VS Code 拡張 + CLI) の会話履歴・エージェント運用を可視化するツールです。

## チェックリスト

- Claude Code 拡張がインストールされている
- ターミナルで `claude --version` が実行できる
- `~/.claude/settings.json` が存在する（初回起動時に自動生成）

## 次のステップ

- 上のリンク「Claude Code パネルを開く」で利用率メニューを起動できます
- 利用率メニューから claude.ai/settings/usage で残量を確認できます
