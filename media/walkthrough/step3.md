# ③ /csm-ask-agent スキルをインストール

`/csm-ask-agent` は取締役が部下エージェントに指示を送るためのカスタムスキルです。Claude Code のスラッシュコマンドとして動作します。

## インストール後にできること

```
/csm-ask-agent csm-impl "セッション一覧の表示速度を改善して"
/csm-ask-agent daros-spec "登録APIの仕様を整理"
```

## 判断・注意

- グローバルインストールは `~/.claude/skills/csm-ask-agent/` に配置します
- Claude Code 2.1+ 系のスキル機能に依存します
- インストールされていない環境では、コマンド呼び出しが「使い方ガイドを開く」の案内に切り替わります

## 次のステップ

インストール後、ステータスバー横のヘルプアイコンから使い方ガイドを開けます。
